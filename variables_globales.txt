Les variables marquées avec extern sont déclarées globalement mais initialisées dans d'autres fichiers. Les variables static sont locales au fichier.

Doublons
Dans sht31_task.c et dans dht_task.c:

static float last_published_temp = NAN;
static float last_published_hum = NAN;
static uint32_t last_publish_ms = 0;

Dans thermostat_task.c,
static float dht_temperature = NAN;
static float sht31_temperature = NAN;
static bool dht_valid = false;
static bool sht31_valid = false;

HANDLES & RESSOURCES (À GARDER GLOBALES)
Ces variables DOIVENT rester globales (pas d'événement pour ça):
// ✅ GARDER globales (ressources bas-niveau):
g_i2c_mutex              // Mutex physique
i2c_bus_handle           // Handle I2C hardware
g_app_event_group        // EventGroup FreeRTOS
bus_mutex                // Mutex event_bus
oled_queue              // Queue OLED
thermostat_queue        // Queue thermostat
video_buffer[]          // Buffer VRAM

// Ajouter dans event_bus.h les événements manquants:
typedef enum {
    EVENT_SENSOR_LAST_PUBLISHED,  // Cache du dernier publish
    EVENT_RELAY_STATE_CHANGED,    // État relais change
    EVENT_THERMOSTAT_TARGET_CHANGED  // Consigne change
} event_type_t;

// Dans dht_task.c & sht31_task.c:
// ✗ Supprimer: static float last_published_temp
// ✓ Remplacer par: event_bus_publish(EVENT_SENSOR_LAST_PUBLISHED)

// OLED s'abonne aux capteurs DIRECTEMENT
event_type_t oled_filter[] = {
    EVENT_SENSOR_DHT,
    EVENT_SENSOR_SHT31,
    EVENT_RELAY_SET,
    EVENT_THERMOSTAT_SET
};
oled_queue = event_bus_subscribe("oled", oled_filter, 4);
// Puis lit depuis la queue, PAS de variable globale
